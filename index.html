Komit AI Agent

A sophisticated multi-subflow AI agent built entirely in n8n. The agent intelligently routes user requests through 6 specialized subflows, each handling a distinct domain — from media search and location discovery to Claude-powered reasoning and automated output delivery.

Giphy & Media Subflow

Handles animated media search and GIF delivery via Giphy API integration

Google Maps Subflow

Location intelligence — places search, directions, and geo-data processing

Data Processing Subflow

Structured data extraction, transformation, and routing between agent nodes

Claude AI Reasoning Subflow

LLM-powered intent analysis, response generation, and decision orchestration

Workflow Orchestration Subflow

Central routing hub that delegates tasks to the appropriate specialized subflow

Output & Delivery Subflow

Formats and delivers final responses back to the user across channels
