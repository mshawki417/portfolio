# Laura Gonzalez Portfolio

This folder contains a full static copy of the portfolio site from https://www.laugon.com/.  

## Folder structure
```
portfolio/
├─ index.html      # Main HTML page
├─ style.css       # All styling (dark mode, gradients, glass‑morphism, micro‑animations)
├─ script.js       # Navigation, typing animation, counters, charts, theme switcher, etc.
└─ assets/         # Profile picture and project screenshots
```

## How to view locally
1. **Option 1 – Simple double‑click**
   - Open `index.html` in a modern browser (Chrome/Edge/Firefox).  
   - All assets are relative, so it works without a server.
2. **Option 2 – Static server (recommended for full Chart.js functionality)**
   - Install a tiny dev server if you have Node.js:
     ```bash
     npx -y serve ./
     ```
   - Or use Python (already bundled):
     ```bash
     python -m http.server 8000
     ```
   - Open `http://localhost:8000` in the browser.

## Deployment
You can host the folder on any static‑site provider (GitHub Pages, Netlify, Vercel, Cloudflare Pages, etc.).  Just push the `portfolio` directory to the repository root and configure the provider to serve `index.html`.

## Customisation
- Edit `index.html` to change text, links, or project entries.
- Replace images in `assets/` with your own.
- Modify colours in `style.css` (accent variables at the top).
- The theme toggle works out‑of‑the‑box; it remembers the choice in `localStorage`.
