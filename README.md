- **Micro-animations:** Smooth reveal animations on scroll and interactive hover effects on project cards and buttons.
- **Responsive Layout:** fully optimized for mobile, tablet, and desktop viewing.

## 💻 How to Run Locally
Since this is a static website, you don't need any complex build tools to run it.

**Option 1: Direct File Access**
Simply double-click the `index.html` file to open it in your default web browser.

**Option 2: Local Web Server (Recommended)**
If you have Python installed, you can run a quick local server:
```bash
python -m http.server 8000
```
Then navigate to `http://localhost:8000` in your browser.

## 🚀 Deployment
This project is ready to be hosted on any static site provider:
- **GitHub Pages:** Push to a repository and enable GitHub pages from the settings.
- **Netlify / Vercel:** Connect your GitHub repository, and it will deploy instantly.
